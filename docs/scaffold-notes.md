# Scaffold notes - Hockey Ops Player Directory

## What we generated

- TanStack Start app with React, TypeScript, Vite, and Tailwind CSS
- No player/games product features yet (routes come next)
- Built from scratch following the official TanStack Start "Build from Scratch" docs

## Key files

| File | Purpose |
|------|---------|
| `package.json` | Dependencies and scripts (`dev`, `build`) |
| `vite.config.ts` | Vite + TanStack Start plugin + React plugin + Tailwind v4 plugin |
| `tsconfig.json` | TypeScript compiler options (react-jsx, Bundler resolution, ES2022) |
| `src/styles.css` | Global styles; imports Tailwind via `@import 'tailwindcss'` |
| `src/router.tsx` | Creates the TanStack router instance with the generated route tree |
| `src/routes/__root.tsx` | Root layout: html/head/body shell, meta tags, stylesheet link |
| `src/routes/index.tsx` | Home route at `/` with placeholder heading |
| `src/routeTree.gen.ts` | Auto-generated by TanStack Router (do not edit by hand) |

## Dependencies installed

**Runtime:** @tanstack/react-start, @tanstack/react-router, react, react-dom

**Dev:** vite, @vitejs/plugin-react, typescript, @types/react, @types/react-dom, @types/node, tailwindcss, @tailwindcss/vite

## Note on Tailwind v4

Tailwind v4 does not use a `tailwind.config.ts` file. Configuration is handled by the `@tailwindcss/vite` plugin added in `vite.config.ts`. The only CSS file needed is `src/styles.css` with `@import 'tailwindcss'`.
